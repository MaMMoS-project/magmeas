    "# Getting started\n",
    "## Introduction\n",
    "\n",
    "This page gives a short overview over the basic usage and functionality of [magmeas](https://github.com/MaMMoS-project/magmeas). For this, we are going to use VSM-data from a publically available [example dataset uploaded to Nomad](https://nomad-lab.eu/prod/v1/gui/user/uploads/upload/id/dyT-vLgKTkqK5JeSy_HWwA/files/IFW_VSM_RawData).\n",
    "\n",
    "\n",
    "## General concepts\n",
    "\n",
    "The classes defined in `magmeas` should be understood as `mammos_entity.EntityCollection` with extra functionality suited for handling magnetometry data. It is worth the time to familiarise yourself with the [EntityCollection](https://mammos-project.github.io/mammos/api/mammos_entity.html#mammos_entity.EntityCollection) first.\n",
    "\n",
    "The main class of magmeas is `Sweep` and handles the initialisation, some general calculations, IO-functionality and some basic plotting. All other classes inherit this behaviour and just add some additional functionality for specific use-cases.\n",
    "\n",
    "\n",
    "## Initialisation\n",
    "\n",
    "`Sweep` objects can be initialised as empty containers. New entities can always be added later. Alternatively, it is possible to pass entities as keyword arguments during the initialisation. As always, `mammos_entity.Entity` objects should be used wherever possible to not just incorporate numerical, but also dimensional and ontological information."

    "## Importing measurement data\n",
    "\n",
    "`magmeas` was written with the analysis of **experimental** magnetometry data in mind. In order to do this, we'll have to get the experimental data into the classes of `magmeas` somehow. As you have just seen, this can always be done manually. Do your own reading and processing of data first and then assign it to the `magmeas` object.\n",
    "\n",
    "However, some import functionality for common data files one might get from magnetometry equipment is already included in `magmeas`. Here is an example for an $M(H)$ measurement acquired on a 14 T PPMS from Quantum Design. The import methods are written so that they assign all of the data to the object they were called from and also return this object so that it can be quickly defined in just one line."
